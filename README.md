# Homebrew Tap

Homebrew formulae for [Baseline](https://github.com/dawson-design/baseline) and [Manifest](https://github.com/dawson-design/manifest).

## Installation

```bash
brew install dawson-design/tap/baseline
brew install dawson-design/tap/manifest
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `baseline` | Strongly typed, effect-based programming language |
| `manifest` | Living feature documentation for AI-driven development |

## Updating

```bash
brew update
brew upgrade baseline
brew upgrade manifest
```
